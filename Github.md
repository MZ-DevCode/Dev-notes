# 🐙 GitHub & Git Cheat Sheet

> **Git** — система контроля версий (локально).  
> **GitHub** — облачный сервис для хранения ваших Git-репозиториев.

---

## 🚀 Основной рабочий цикл (Workflow)

Когда вы изменили файл и хотите отправить его в облако:

1.  **Проверить статус:** `git status` (покажет, какие файлы изменились).
2.  **Подготовить:** `git add .` (добавить все изменения) или `git add filename.md`.
3.  **Сохранить (Коммит):** `git commit -m "описание того, что сделал"`.
4.  **Отправить:** `git push origin main`.

---

## 🛠 Полезные команды


| Команда | Описание |
| :--- | :--- |
| `git init` | Инициализировать новый репозиторий в папке. |
| `git clone <url>` | Скачать чужой проект к себе на компьютер. |
| `git pull` | Забрать свежие изменения из облака (если кто-то другой их туда залил). |
| `git log` | Посмотреть историю всех сохранений (коммитов). |
| `git diff` | Посмотреть, что именно изменилось в коде с прошлого раза. |

## 🔒 Настройка безопасности

### Как не вводить пароль каждый раз?
Если вы используете HTTPS (как сейчас), выполните эту команду:
```bash
git config --global credential.helper store
```

## 🌿 Ветки (Branches)

Ветки позволяют работать над разными версиями проекта одновременно, не мешая друг другу. Основная ветка обычно называется `main` или `master`.

### Основные команды для работы с ветками

| Команда | Описание |
| :--- | :--- |
| `git branch` | Показать список всех локальных веток (текущая отмечена звёздочкой) |
| `git branch <название>` | Создать новую ветку |
| `git checkout <название>` | Переключиться на другую ветку |
| `git checkout -b <название>` | Создать новую ветку и сразу переключиться на неё |
| `git merge <название>` | Влить изменения из указанной ветки в текущую |
| `git branch -d <название>` | Удалить ветку (локально) |
| `git push origin --delete <название>` | Удалить ветку на GitHub |
| `git push origin <название>` | Отправить новую ветку в удалённый репозиторий |

### Типичный сценарий работы с ветками

```bash
# 1. Создать новую ветку для своей задачи
git checkout -b feature/new-feature

# 2. Сделать изменения и закоммитить их
git add .
git commit -m "добавил новую функцию"

# 3. Отправить ветку на GitHub
git push origin feature/new-feature

# 4. Переключиться обратно на основную ветку
git checkout main

# 5. Влить свою ветку в основную (после проверки и одобрения)
git merge feature/new-feature

# 6. Удалить ненужную ветку
git branch -d feature/new-feature
```
