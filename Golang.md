# 🔵 Go (Golang)

> **Go** — это компилируемый язык от Google с открытым исходным кодом. Он сочетает производительность C++ с простотой Python и встроенной поддержкой многопоточности.

---

## ⚡️ Ключевые особенности

*   **Статическая типизация:** Ошибки типов ловятся при компиляции.
*   **Компиляция в бинарник:** Программе не нужен интерпретатор; она собирается в один исполняемый файл.
*   **Concurrency (Горутины):** Легковесные потоки (`goroutines`) позволяют запускать миллионы параллельных задач.
*   **Строгий стиль:** Неиспользуемые переменные или импорты приводят к ошибке компиляции.

---

## 🛠 Базовый синтаксис

### 📦 Переменные и типы данных

В Go строгая статическая типизация. Переменную нельзя переопределить другим типом данных после объявления.

#### 1. Объявление переменных

| Способ | Синтаксис | Особенности |
| :--- | :--- | :--- |
| **Полный** | `var name string = "Go"` | Можно объявлять на уровне пакета (вне функций). |
| **Краткий** | `name := "Go"` | **Только внутри функций**. Тип определяется автоматически. |
| **Групповой**| `var ( a = 1; b = 2 )` | Удобно для объявления нескольких настроек сразу. |

#### 2. Нулевые значения (Zero Values)
Если вы объявили переменную, но не дали ей значение, Go присвоит ей «дефолт»:
*   `int`, `float` → `0`
*   `string` → `""` (пустая строка)
*   `bool` → `false`
*   `указатели, интерфейсы, слайсы` → `nil`

#### 3. Константы (Constants)
Константы вычисляются на этапе компиляции. Им нельзя присвоить результат работы функции (например, время).
```go
const Pi = 3.14
const (
    StatusOk = 200
    StatusError = 500
)
// Использование iota (авто-инкремент для перечислений)
const (
    A = iota // 0 — iota начинается с 0
    B        // 1 — автоматически увеличивается
    C        // 2 — ещё +1
)

// Можно использовать для удобных перечислений (enum-подобное поведение)
func main() {
    fmt.Println(A, B, C) // 0 1 2
}
```
#### 4. Целочисленные типы (Integers)


| Тип | Размер | Описание |
| :--- | :--- | :--- |
| `int` | 32 или 64 бит | Зависит от платформы (рекомендуется по умолчанию) |
| `uint` | 32 или 64 бит | Беззнаковое целое (только положительные) |
| `int8` .. `int64` | 8 - 64 бит | Числа со знаком с фиксированным размером |
| `uint8` .. `uint64`| 8 - 64 бит | Числа без знака с фиксированным размером |
| `byte` | 8 бит | Псевдоним (alias) для `uint8` |
| `rune` | 32 бит | Псевдоним для `int32` (хранит один символ Unicode) |

#### 5. Числа с плавающей точкой (Floating Point)


| Тип | Точность | Описание |
| :--- | :--- | :--- |
| `float32` | 7 знаков | Стандарт IEEE-754, 32 бита |
| `float64` | 15 знаков | Рекомендуется использовать по умолчанию (64 бита) |
| `complex64` | - | Комплексное число (float32 для реальной и мнимой частей) |
| `complex128`| - | Комплексное число (float64 для частей) |

#### 6. Логический тип (Boolean)


| Тип | Значения | Особенности |
| :--- | :--- | :--- |
| `bool` | `true`, `false` | Нельзя привести к `int` (0 или 1) напрямую |

#### 7. Строки (Strings)


| Тип | Описание | Особенности |
| :--- | :--- | :--- |
| `string` | Набор байт | **Immutable** (неизменяемые). Хранят текст в UTF-8. |

#### 8. Raw string literals (сырые строковые литералы)

Raw string literals — это строки, записываемые в обратных кавычках `` ` ``.  
Они не обрабатывают escape-последовательности и сохраняют текст “как есть”.

```go
text := `Hello\nWorld`
fmt.Println(text) // Hello\nWorld
```

### ⚠️ Важные правила работы с типами

1. **Явное приведение:**
   В Go нельзя складывать разные типы (даже `int` и `int32`). Нужно всегда приводить вручную:
   ```go
   var a int = 10
   var b int32 = 20
   // c := a + b // ОШИБКА
   ```

### Слайсы 

В Go **Слайс** — это динамический дескриптор сегмента массива. В отличие от массивов, размер слайса не является частью его типа, что делает его гибким инструментом для работы со списками данных.

---

#### 1. Анатомия слайса (Внутреннее устройство)
В памяти Go слайс — это маленькая структура из трех полей:
1.  **Pointer** (Указатель) — адрес начала данных в базовом массиве.
2.  **Length (len)** — текущее количество элементов в слайсе.
3.  **Capacity (cap)** — максимальное количество элементов, которое слайс может вместить (начиная с указателя) без перевыделения памяти.

---

#### 2. Способы создания слайса


| Способ | Синтаксис | Когда использовать |
| :--- | :--- | :--- |
| **Литерал** | `s := []int{1, 2, 3}` | Когда значения известны заранее. |
| **Через make** | `s := make([]int, 5, 10)` | Когда известны размер (5) и запас (10) для скорости. |
| **Из массива** | `s := arr[1:4]` | Чтобы работать с частью существующего массива. |
| **Нулевой** | `var s []int` | Создает `nil` слайс (длина и емкость = 0). |

---

#### 3. Главные функции: `append` и `copy`

**Добавление элементов (`append`):**
Если в слайсе нет места (`len == cap`), `append` создает новый массив большего размера, копирует туда данные и возвращает новый слайс.
```go
s := []int{10, 20}
s = append(s, 30)             // Добавить один элемент
s = append(s, 40, 50, 60)      // Добавить несколько
s = append(s, otherSlice...)   // Слить два слайса (развертывание через '...')
```

**Копирование элементов (`copy`):**
Функция copy(dst, src) выполняет копирование значений из одного слайса в другой.
```go
type Flight struct {
    Number   string `json:"flight_number"` // В JSON будет "flight_number"
    Secret   string `json:"-"`             // Игнорировать в JSON
}

src := []int{1, 2, 3, 4}       // Выделен массив в куче; слайс получил ptr, len: 4, cap: 4
dst := make([]int, len(src))   // Выделен ВТОРОЙ независимый массив; len обязана быть > 0
n := copy(dst, src)            // Побайтовое копирование данных; dst и src теперь автономны
```

4. Capacity и рост слайса (Capacity & Growth)

У слайса есть ёмкость (cap), которая ограничивает количество элементов без перевыделения памяти.

```go
s := make([]int, 3, 5)

fmt.Println(len(s)) // 3
fmt.Println(cap(s)) // 5

# Массивы в Go

**Массив** — это последовательность элементов одного типа фиксированной длины. Длина массива является частью его типа.

Это означает, что [3]int и [4]int — разные типы, несовместимые друг с другом.
```
---

## 1. Объявление массива
```
var arr [5]int               // массив из 5 нулей: [0, 0, 0, 0, 0]
var arr2 [3]string = [3]string{"a", "b", "c"}  // полная форма
arr3 := [3]int{1, 2, 3}      // короткая запись
arr4 := [...]int{10, 20, 30} // длина вычисляется автоматически (...)
```
---

## 2. Доступ к элементам

Индексация начинается с 0.
```
arr := [3]int{10, 20, 30}
fmt.Println(arr[0]) // 10
arr[1] = 99
fmt.Println(arr)    // [10, 99, 30]
```
---

## 3. Длина массива (len)

Длина фиксирована и не может быть изменена.
```
arr := [4]string{"x", "y", "z", "w"}
fmt.Println(len(arr)) // 4
```
---

## 4. Перебор массива

Классический for по индексу:
```
arr := [3]int{5, 10, 15}
for i := 0; i < len(arr); i++ {
    fmt.Println(i, arr[i])
}
```
for range (рекомендуется):
```
for index, value := range arr {
    fmt.Println(index, value)
}
```
Если нужны только значения:
```
for _, value := range arr {
    fmt.Println(value)
}
```
---

## 5. Массивы — значения, а не ссылки

Важнейшее правило: в Go массивы передаются по значению (копируются). Функция получает копию, изменения внутри функции не влияют на оригинал.
```
func change(arr [3]int) {
    arr[0] = 999
}

func main() {
    x := [3]int{1, 2, 3}
    change(x)
    fmt.Println(x) // [1, 2, 3] — не изменился
}

Чтобы изменить оригинал, нужно передавать указатель:

func changePtr(arr *[3]int) {
    arr[0] = 999
}

func main() {
    x := [3]int{1, 2, 3}
    changePtr(&x)
    fmt.Println(x) // [999, 2, 3]
}
```
---

## 6. Сравнение массивов

Массивы можно сравнивать через == и !=, если их элементы сравнимы.
```
a := [2]int{1, 2}
b := [2]int{1, 2}
c := [2]int{2, 3}

fmt.Println(a == b) // true
fmt.Println(a == c) // false
```
---

## 7. Многомерные массивы
```
// Матрица 2x3
var matrix [2][3]int = [2][3]int{
    {1, 2, 3},
    {4, 5, 6},
}

fmt.Println(matrix[1][2]) // 6
```
---

## 8. Зачем нужны массивы, если есть слайсы

| Используй массив, когда: | Используй слайс, когда: |
|--------------------------|--------------------------|
| Размер известен и фиксирован | Нужна динамическая структура |
| Нужна гарантия, что размер не изменится | Нужно добавлять/удалять элементы |
| Количество элементов невелико | Работаешь с большими объёмами данных |
| Хочешь передавать копии (по значению) | Нужна ссылочная семантика |

---

## 9. Резюме

| Характеристика | Массив ([n]T) |
|----------------|---------------|
| Длина | Фиксирована, часть типа |
| Память | Выделяется сразу на стеке (или в куче, если большой) |
| Передача в функцию | По значению (копия) |
| Сравнение | Да (==, !=) |
| Используется на практике | Редко. Почти всегда используют слайсы |

На практике массивы в Go используются редко. Для повседневной работы почти всегда берут слайсы — они гибче и удобнее. Но понимать массивы нужно, чтобы понимать, как работают слайсы под капотом.

### 4. Maps

**Map** в Go — это встроенный тип для хранения неупорядоченных пар «ключ-значение». Это аналог ассоциативных массивов в PHP, работающий как хэш-таблица (поиск за **O(1)**).

---

#### 1. Способы создания мапы


| Способ | Синтаксис | Комментарий |
| :--- | :--- | :--- |
| **Литерал** | `m := map[string]int{"Go": 10}` | Создание с начальными данными. |
| **Через make** | `m := make(map[string]int)` | Пустая мапа, готовая к записи. |
| **С запасом** | `m := make(map[string]int, 100)` | Оптимизация: резервирует память под 100 элементов. |
| **Нулевая** | `var m map[string]int` | **nil** мапа. Читать можно (вернет 0), **писать нельзя (panic)**. |

---

#### 2. Основные операции (CRUD)

```go
m := make(map[string]int)

// 1. Запись и Обновление
m["apple"] = 5 

// 2. Чтение (если ключа нет, вернет zero value типа - 0)
price := m["apple"] 

// 3. Проверка существования (Comma ok idiom)
val, ok := m["orange"]
if ok {
    fmt.Println("Цена найдена:", val)
}

// 4. Удаление (безопасно, даже если ключа нет)
delete(m, "apple") 

// 5. Итерация (порядок ВСЕГДА случайный)
for key, value := range m {
    fmt.Printf("%s: %d\n", key, value)
}
```

### Структуры (Structs)

**Struct** — это пользовательский тип данных, представляющий собой набор полей. В Go это единственный способ группировки данных (заменяет классы).

---

#### 1. Объявление и инициализация

```go
type User struct {
    ID    int
    Name  string
    Email string
}

// Способы создания:
u1 := User{1, "Alice", "a@a.com"}   // По порядку полей (не рекомендуется)
u2 := User{ID: 2, Name: "Bob"}      // По именам (рекомендуется, Email будет "")
u3 := new(User)                     // Возвращает указатель *User, поля обнулены
```

### 2. Встраивание
В Go нет наследования. Используется композиция: одна структура встраивается в другую как анонимное поле.

```
type Admin struct {
    User       // Встроенное поле (Anonymous field)
    Level int
}

ad := Admin{User: User{Name: "Admin"}, Level: 10}
fmt.Println(ad.Name) // Поля User доступны напрямую из Admin (ad.Name)
```

### Интерфейсы (Interfaces)

**Интерфейс** в Go — это тип, который определяет набор методов (контракт). Если структура реализует все методы интерфейса, она автоматически считается реализацией этого интерфейса.

---

### 1. Объявление и реализация

```go
// Объявление интерфейса
type Shaper interface {
    Area() float64
}

type Circle struct {
    Radius float64
}

// Реализация метода Area для структуры Circle
// Нет ключевого слова "implements" — реализация происходит неявно
func (c Circle) Area() float64 {
    return 3.14 * c.Radius * c.Radius
}
```

### 2. Пустой интерфейс (interface{} или any)
Интерфейс, который не содержит методов. Ему соответствует любой тип данных. В Go 1.18+ введен псевдоним any.
```go 
var x any
x = 42          // int
x = "hello"     // string
x = Circle{5}   // struct
```

### 3. Приведение типов (Type Assertion)
Так как интерфейс может хранить любой тип, иногда нужно проверить, что именно там находится.

```go
val, ok := x.(string) // Проверка: "содержит ли x строку?"
if ok {
    fmt.Println("Это строка:", val)
}
```
